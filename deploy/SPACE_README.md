# BiomedRAG

Ask a question about glioma research and get an answer that cites the PubMed papers it used, or an honest
refusal when the abstracts do not contain the answer. Research tool only; not medical advice.

Code, evaluation and write-up: see the GitHub repository linked from the project page.
