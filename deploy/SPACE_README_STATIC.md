# BiomedRAG

Ask a question about glioma research and get an answer that cites the PubMed papers it used, or an honest
refusal when the abstracts do not contain the answer. Research tool only; not medical advice.

This page shows saved answers to example questions, produced by the real pipeline. The full system answers any
question when run on your own computer.

Code, evaluation and write-up: https://github.com/sritipeach1/biomed-rag
